# Documentation index

Start with the one you need, you should not have to read all of these.

| Document | Read this when… |

| [USER_GUIDE.md](USER_GUIDE.md) | You want to **use** the app: installation, first run, every page, troubleshooting and FAQ. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | You want to **change the code**: module map, task queue, threading and safety contracts. |
| [ROAST.md](ROAST.md) | You want to know **what was broken in the early releases** and exactly what was fixed. |
| [ci-workflow.yml.example](ci-workflow.yml.example) | You want to enable GitHub Actions (copy it to `.github/workflows/ci.yml`). |
| [`../CONTRIBUTING.md`](../CONTRIBUTING.md) | You want to contribute or add an app to the catalogue. |
| [`../CHANGELOG.md`](../CHANGELOG.md) | You want the release history. |

The main [`README.md`](../README.md) is the quick-start entry point.
