# Bundled catalogue marks

The monochrome marks in this directory are derived from [Simple Icons](https://github.com/simple-icons/simple-icons), revision `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`. Their SVG artwork is distributed under CC0 1.0; see `LICENSE.simple-icons.md`. They were rendered as white, transparent 64×64 PNGs for use on Preen's icon tiles. Brand names and logos remain trademarks of their respective owners; inclusion does not imply endorsement.

Preen prefers an application's installed icon. These marks are an offline fallback for matching catalogue entries only. Unmatched applications use an explicitly generic initial tile rather than an invented logo.
